# Arc 荧光绿界面与实时链观察

本轮对应用户授权的参考图 UI 重做与实时数据接入。界面版本为 `atl-ui-v1.3.0`；资金规则继续使用 `atl-v1.2.1`，数据库迁移仍为 6。范围仅限既有 Arc 只读组件。

## 视觉与交互

黑底、荧光绿数值、细线分类流、环形分布、报酬柱线图、线框图标和切角卡片沿用参考图风格。动效包括流线亮度、环形轨迹、实时指示灯和实际资金边高亮；系统的“减少动态效果”设置关闭动画。动态图不伪造金额变化。

首页总览与列表共享固定 `snapshotRunId`。统计范围是本快照按编号排序的前 100 项，截断显式显示；分类流线只表示任务数量。报酬图仅比较前 12 项约定报酬，使用整数原子单位计算相对高度，精确数值仍来自原结果；缺失报酬不画零值或跨缺口连线。图形键盘入口、状态分类、逐项回放保留固定快照。

任务详情、报告、消费者仍共享原结算结果和证据模型；费用、资金归属、待领取与清偿规则未改变。没有把参考图中的营收、利润、增长率、预测或预算目标写入生产数据。

## 新数据与边界

`GET /v1/dashboard` 使用既有数据库的只读列表投影及证据标识，不另建生产记录权威。`GET /v1/live` 使用部署锁登记的免费 dRPC 和原安全只读传输，核对链 ID 与来源声明的 finalized 区块，并返回区块摘要、时间、来源和原始观察。官方主网参数与 dRPC 来源在 [Arc 官方连接文档](https://docs.arc.io/arc/references/connect-to-arc) 核对；未增加付费来源。

所有访问者在单个 API 实例共用进行中的观察。成功和失败后各冷却 30 秒；浏览器每 30 秒读取一次，隐藏标签页停止周期读取，可暂停和手动刷新。观察超过 90 秒标为陈旧；来源区块时间落后 120 秒标为陈旧。两项时间阈值是本界面的新鲜度策略，不是协议最终性参数或历史覆盖阈值。来源冲突、陈旧、未启用/响应缺失和来源故障分别返回；故障不归零，上次成功观察显式标为非当前值。

实时观察未归档，`durable=false`、`formalForensicReady=false`；用户可下载原始观察，但它不成为正式取证证据。已发布资金事实仍按既有采集计划更新。实时区块不证明任务实时到账。发现新资金快照时只显示提示，需用户主动查看，当前分享链接保持固定。
