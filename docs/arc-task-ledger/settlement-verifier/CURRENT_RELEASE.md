# Arc USDC 结算核验器 2.0.0

旧 ArcBounty 规则保持 `atl-v1.2.1`，新核验规则 `zasv-rules-v1.0.0`、解析器 `zasv-usdc-parser-v1.0.0`、接口 `zasv-interface-v1`、报告 `zasv-report-v1`。共享 Arc 包 1.3.0，API/Web 2.0.0，增量数据库迁移 7。健康接口分别公布旧规则、新规则、接口、迁移和执行源码版本。

本次增加尚未保存的 Arc 主网交易核验、原生/ERC-20 同余额镜像归一化、显式收款条件、逐项解释、不可覆盖报告、受控公开分享、原件离线复算、在线重查、独立 API 客户端和对账示例。旧任务、固定快照、金额、游标与原始证据继续使用原数据库和原规则。

原生系统事件是规范资金边；ERC-20 镜像按事件身份及多重集核对。金额使用 18 位最小单位字符串，ERC-20 6 位小数提升为 18 位；同额多笔不合并，Gas 单列。交易发送者与资金付款人不同，收入、支出与净资金转移分别显示。

MATCHED 仅代表所选资金边符合冻结条件。用途、事前约定、订单归属、履约、独立来源一致性及离线主网真实性不在结论中。单来源 RPC 的 finalized 是来源声明；正式完整取证模式保持关闭。

本文件随候选验收更新。最终执行版本、部署镜像、命令、结果、产物摘要与未完成门禁以 [VALIDATION.json](VALIDATION.json) 和 [HANDOFF.md](HANDOFF.md) 为准。旧历史报告不是本轮 PASS。
