# Arc 英文状态文案修复：atl-ui-v1.4.2

用户截图及本轮线上复现显示：英文界面的会话报告列表仍显示“匹配 / 不匹配”。报告正文有直接的双语状态文案，但列表先把状态代码变成中文，再依赖不完整的通用翻译表，因此遗漏部分动态状态。

## 复用与修复

沿用现有全局语言设置、浏览器偏好、报告列表和固定报告，不新增翻译服务或依赖。核验状态通过 `verifier-labels.ts` 从语义代码直接选择中文或英文；报告列表和报告标题共用该映射。逐项检查标题、资金类型、原生/ERC-20 接口与镜像核对状态也从同一映射选择语言。未知扩展代码保持原标识，原始证据与固定报告事实不翻译或重写。

本次仅修正显示文案及界面版本声明。数据库迁移仍为7，金额、结算规则、原件、分享权限和报告版本不变。英文默认及显式中文偏好保持原有约定。

## 验证与发布记录

单元检查覆盖全部34个显示代码的中英边界及未知扩展代码；浏览器回归使用隔离真实数据库产生匹配与不匹配报告，返回首页、刷新、展开列表、切换中文再切回英文，直接断言列表语言。另保留金额、冻结报告、草稿、权限、手机、导出与打印回归。

本轮执行收据记录当前源码文件摘要、命令、实际结果和日志；线上操作只读取原有报告与任务，不为语言修复另建主网核验报告。最终部署版本、页面资源摘要、旧报告/#18/游标对照及线上中英截图在后续发布收据中单列。既有1.4.1记录保留为历史，不冒充本次通过证据。
