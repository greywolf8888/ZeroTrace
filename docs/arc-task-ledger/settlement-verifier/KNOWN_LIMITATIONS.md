# 当前边界与限制

- 单登记 RPC 来源；来源独立性、收据树包含证明、完整历史与完整取证结论未验证。finalized 仅为来源声明。离线摘要和复算无法认证主网原件；自洽合成包也可通过完整性检查。
- MATCHED 不证明付款用途、订单归属、事前约定、履约、跨交易余额或到账后支配。Gas、gross movement 与 net movement 分列；用户选择决定核对范围。
- 明确合成语义反例位于测试路径，不是实际稀有主网场景。未观察到的主网案例不能标为已观察。
- 私有所有权依赖 7 天不可猜测会话，未实现账户登录、凭据找回或跨设备所有权恢复。报告原件本身没有 TTL。公开固定版本不能撤回，请先审阅预览。
- ArcBounty 协议条件绑定旧规则的固定持久投影及原始证据；本版离线复算不重新执行全部旧协议引擎，也不认证其链来源。未知资金归属不能生成确定协议条件。
- 有界存储 1000 报告/128MiB 原件，无无限匿名队列。中断请求需显式新 POST 处理，GET 状态不回收工作。多实例部署仍需共享原 PG 配额；当前只复用单实例服务。
- 对账示例只在自己的 SQLite namespace 防重，不是生态采用或实际结算系统；未向第三方、比赛或资助方提交。
- Northflank 本轮仅复用既有规格，不添加资源、储存、实例、支付方式或付费数据源。实际费用观测与剩余额度分开，不能保证长期免费。平台专用监测扩展的跨平台恢复不等于 Arc schema 恢复。
- 最终未通过、外部不可执行及尚未观察的门禁逐项记录在 VALIDATION.json；不能用构建或测试数量替代用户闭环。
