## 故障与修复记录

- Windows 原包路径索引及 npm.CMD 双引用问题通过兼容入口处理，原研究包未改。包校验读取 8 阶段、42 情景、20 来源，manifest 一致。
- 独立导出排除浏览器报告、测试结果、coverage/output 等生成目录；最终归档无私有运行日志。workspace 链接与 Compose 相对构建路径已修复；导出闭包不依赖原仓库其他模块或私有 npm/Git 地址。
- 根测试发现器曾重复读取导出中的测试并争用测试库；已排除导出/研究包/私有状态及 Arc 浏览器目录。重复执行的 76 项收据与受争用失败保留为过期记录。
- 原 F 盘测试库清理操作出现 10 秒 statement timeout；PostgreSQL 日志记录一次 checkpoint 同步约 117 秒。本轮另建 C 盘临时测试集群、保持 fsync 与原有 10 秒限制，根目录 16 项与独立目录 16 项均在约 3–4 秒通过。未修改业务超时或原生产数据。
- 完整构建前原模块入口未生成，首次全仓库单元收集失败；完整构建后 197 个测试文件通过。
- 架构检查拒绝领域包直接引入 pg；PostgreSQL 实现移至 API 基础设施层，核心仅依赖 LedgerRepository 契约，数据库 schema 与权威来源不变。
- Rust 首次冷构建达到有界超时，后续发现原桌面端 sidecar 尚未生成；运行现有真实 sidecar 构建流程后，完整 Rust 工作区测试通过。生成二进制留在原忽略目录，不纳入 Arc 导出或提交。
