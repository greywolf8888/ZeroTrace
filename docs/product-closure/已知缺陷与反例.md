1. Windows Playwright 默认 12 workers 导致 teardown 超时；限制为 2 后全量 42/42，并完成第二轮自启动抽样。
2. `A Must-Link B`、`B Must-Link C`、`A Cannot-Link C` 的传递冲突现会 fail closed。

4. 正式案件改为 `202 QUEUED` + fenced worker；heartbeat/cancel/retry/stale-result 有故障测试，硬编码 Token 起源映射已移除。

6. `test:formula:diff` 被全局 exclude 永久排除；解除专用门禁排除后又发现 Rust 冷编译超过 15 秒，改用明确 120 秒跨语言预算并连续两轮通过。
7. Rust 全工作区默认并行链接触发 Windows pagefile 1455；`verify:terminal` 限定 `-j 2` 后完整通过，未降低警告或断言。
