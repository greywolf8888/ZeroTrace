# 算法真相审计

| 算法/能力   | 审计前                                               | 当前修复                                                                                         | 仍需真实门禁                                   |
| ----------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ---------------------------------------------- |
| Cannot-Link | 仅检查待合并根的直接 pair，可能被传递 Must-Link 绕过 | 在组件层检查冲突，并分别构造 confirmed/scenario/upper partitions；间接矛盾 fail closed           | 真实标签语料与服务 hub 反例                    |
| PELT        | O(n²) Optimal Partitioning 被称为 PELT               | 加入候选集剪枝，并增加多变点标准反例                                                             | 大规模差分与基准                               |
| BOCPD       | 残差启发式被称为 BOCPD                               | 输出显式 run-length posterior，逐行归一化并加入分布漂移反例                                      | 在线真实流校准                                 |
| V3          | 虚拟储备估计可被误读为 exact                         | 重命名为研究近似；仅 pinned archive fork + bytecode verified + replay hash match 才可 ReadyExact | 跨 tick 或真实 VM 执行                         |
| 多路由      | 贪心 split-and-fill 可被误读为全局优化               | 输出 `ApproximationResearchOnly`；仅单 V2 venue 标为 exact                                       | 共享池状态、重复池、顺序依赖反例与全局最优求解 |
| 全盘退出 U  | 未计算时传字符串 `0`                                 | 改为 typed Unknown，只有提供 bounds 才 Known                                                     | 全盘共享状态模拟                               |

Evidence score 仍不是校准概率；CEX/Bridge/Privacy 边界仍不是 confirmed realization；当前状态仍不是历史状态。
