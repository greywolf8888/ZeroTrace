# 页面与数据源映射

| 当前页面/入口                          | 数据源                                        | 真实状态           | 产品闭环处置                                                         |
| -------------------------------------- | --------------------------------------------- | ------------------ | -------------------------------------------------------------------- |
| Token 盘面分析                         | `/api/v2/tokens/.../analyze`                  | API_ONLY / PARTIAL | 作为工作台统一查询入口；移除默认示例 Token；正式模式改为 durable job |
| 概览                                   | health/capabilities/platform/provider APIs    | PARTIAL            | 去除营销 Hero，改为最近案件、运行任务、告警、数据源健康              |
| Campaign/供应/实体/资金/利润/情景/证据 | 各自 v1/v2 API                                | PARTIAL            | 不再作为一级导航，归入案件内二级页签或 Developer 区                  |
| 调查/案件                              | investigation/report APIs                     | PARTIAL            | 建立固定 Case Header 与 stage/coverage/evidence 上下文               |
| 健康/控制                              | health/provider/storage APIs                  | CONNECTED/PARTIAL  | 合并为“数据源与系统”                                                 |
| 告警                                   | forensic campaign alert/capture schedule APIs | PARTIAL            | 合并为“监控与告警”，补 cursor/finality/reorg/withdraw 状态           |
| Desktop                                | Rust workspace launcher                       | FIXTURE_ONLY       | 不得标为安装版；需 production web + 受控 API sidecar + 动态 loopback |

普通用户卡片必须显示来源、区块覆盖、Snapshot/Finality、更新时间、Unknown/Partial 原因、Evidence 入口和重试计划。当前无法回答这些问题的内容保持 Developer/Partial，不以成熟卡片呈现。
