# 盘面结构数据字典

| 对象                   | ID 前缀 | 含义               |
| ---------------------- | ------- | ------------------ |
| ForensicFinding        | fnd_    | 带证据与反证的发现 |
| ReportEnvelope         | frp_    | 不可变报告外壳     |
| Investigation          | inv_    | 调查               |
| SupplyCell             | cel_    | 供应立方体单元格   |
| RoleAssessment         | rol_    | 角色评估           |
| MarketControlCampaign  | mcc_    | 坐庄活动           |
| TacticHypothesis       | tac_    | 手法假设           |
| EconomicLot            | lot_    | 经济批次           |
| MarketWideExitScenario | mwe_    | 全盘退出情景       |
| AnalystDecision        | ads_    | 分析员认定         |
| Case                   | cse_    | 案件包             |
| Job                    | job_    | 工作流作业         |

未知、不可用、过期与未查询不得写成数字 0。
