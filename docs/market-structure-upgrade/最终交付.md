## 8. 启动方式

- **本地最小模式：** `npm run build:packages && npm run dev`（API :8080，Web :5173）。无私钥。
- **完整研究模式：** 配置 `POSTGRES_URL`、链 RPC、对象存储后启动 ingest/semantic worker；先物化供应现实再查 `/market-structure/latest`。
- **LLM 禁用：** 不调用 `/api/v2/llm/validate`；网关默认拒绝无证据与法律结论。
- **LLM 启用：** 只提交已有 Evidence ID 的结构化 JSON；`services/llm-worker` 读 stdin。
- **Sidecar：** Apache AGE / cryo / ETL 仍按既有文档，不进入核心源码复制。
- **数据回填：** 既有 `flap:*` / `actions:capture` / `claims:*` 命令；新盘面需 `POST .../supply-reality`。
- **新建调查：** `POST /api/v2/investigations` 或 UI「案件与调查」。
- **导出案件：** 分析员工作台「提交认定并导出中文案件包」或 `GET /api/v2/cases/:id/export`。

## 9. 证据样例（黄金合成 Token）

主体：`EVM / eip155:56 / 0xccc…c`。快照 block `42`，hash `0xaaa…`。证据 `ev_111…` / `ev_222…` / `ev_333…`。

- **供应守恒：** protocol=1000，wallet 700 SELLABLE_NOW + pool 300 LP_WITHDRAWAL_REQUIRED；`identityHolds=true`；未知差额单独记账。
- **角色占比：** 链上控制者 700；三正交隐匿仓 40（ofProtocolSupply scenario=40）；独立自然交易者 count=1。early 单独 → UNKNOWN。
- **坐庄时间线：** 净流入 +10 后 -4 的变化点切出多活动；无起源时 status=`BOUNDED_OBSERVATION`。
- **手法：** `REMOVE_LP_THEN_SELL` 仅在多家族且替代解释处理后作为 `MODEL_HYPOTHESIS`。
- **资金回流：** 内部转账 `amountU=0`；CEX 50 记 `VENUE_BOUNDARY` 而非销售收入。
- **活动损益：** 内部转账 `realizedNetProfitU={state:known,value:0}`；销售 150-80=70。
- **全盘 RV：** 共享流动性总兑现严格小于孤立报价之和；`isolatedRvSumRejected=true`；seed=42 时 P10≤P50≤P90 可复现。
- **Evidence drilldown：** 信封 `evidenceClosure` 非空，`replayRef.command` 指向 latest GET。

该样例是确定性黄金夹具，不是某监管案件的链上事实。

## 10. 最终结论

**现在能证明（在给定 Snapshot 与 Evidence 闭包内）：**

- 协议供应与单元格是否守恒，销毁/桥接是否被双计；
- 当前可卖 / 需撤 LP / 未知卖出状态的原子量；
- 角色候选为何不能仅凭早期地址或小余额确认；
- 内部转账不产生利润、CEX 只是场所边界；
- 孤立 RV 求和非法，共享流动性退出可复现分位数；
- LLM 输出是否引用已知 Evidence、是否夹带未审计法律结论。

**不能证明：**

- 某地址“就是庄家本人”或“诈骗/操纵已成立”；
- 交易所内部分配、未观测隐私工具另一侧、未查询 RPC 的余额；
- 未校准模型的概率含义；
- 无起源覆盖时的完整坐庄周期。

**仍需分析员确认：** 实体合并/拆分、手法替代解释是否排除、法律定性、链外披露是否构成老鼠仓豁免、案件导出中的认定理由。
