# 未验证边界

- 无本地 BSC Archive / Reth-BSC / Geyser / Bitcoin Core 时，Token 分析不得标记 COMPLETE。
- 无真实标注集时，只输出证据分，不得输出校准概率。
- CEX/Bridge/Privacy 对侧账本不可观测。
- Uniswap v4 Hook、未知字节码、later-context Solana 账户均 fail-closed。
- OIDC IdP、WebAuthn 硬件、WORM Object Lock、24h Soak、签名更新通道依赖运行环境。
- 本机 Docker 端口占用时，集成测试按既有规则 skip，不得改成假 PASS。
- 未配置或探测失败的免费 Key / Trace RPC 插槽保持 UNCONFIGURED；不得把缺能力写成 PASS。
- NodeReal/Ankr 当前 Key 的 debug/trace 命名空间被套餐拒绝；通用 `BSC_TRACE_RPC_URL` 不得声明可用。
- SQD CREATE traces 可闭合已知创建交易的内部 CREATE；不能替代 pinned archive fork 或校准概率。
- 公共无 SLA 节点的理论 RPS 不是实测上限；默认 3–5 RPS 起步。低成本模式 Acquisition/Token/Trace 并发默认 1。
- 配置声明不能代替 ProviderCapabilitySnapshot。
- DuckDB 与 ClickHouse 对同一真实案件的 ResultHash 对照：ClickHouse 未配置时记 NOT_RUN，不得记 PASS。
- 第二次分析历史 RPC=0 仅当 Coverage 已覆盖起源到当前头；未覆盖区间保持未知。
