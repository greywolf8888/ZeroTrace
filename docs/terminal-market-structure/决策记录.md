# 决策记录

1. **基线**：`git fetch origin main` 后保护分支仍为 `58b3ca2c55fab41fe66453fed2f1833735e7ee30`，与提示词包已知 SHA 一致，无远程漂移。
2. **分支**：从 `origin/main` 创建唯一短分支 `agent/terminal-market-structure-v1`。未把本机未推送的 18 个并行提交并入，避免与 squash 合并的 PR #22 产生不可审计的树冲突。
3. **公式权威**：新增 Rust workspace `crates/*`。TypeScript 引擎暂时保留控制面与既有回归；新增差分测试。生产路径的供应守恒、AMM 整数核、PELT、调度器、约束聚类以 Rust 为准。
4. **实盘执行器**：`scripts/live-case-runner.ts` 原先读取不存在的 `ZERO_TRACE_BSC_RPC_URL`，因此永远 `BLOCKED_EXTERNAL`。改为读取 `EVM_BSC_RPC_URLS` / `BSC_RPC_URL`，并在可公开只读端点上做双 Operator 捕获。未完成的 Case 不得写 PASS。
5. **DataFusion**：查询规划器先实现本地索引优先、RPC 成本准入和列式过滤。完整 DataFusion/Parquet SessionContext 在本地索引落地后接入，避免未使用的重依赖冒充完成。
6. **Exact VM**：无钉死 Archive Fork 时 `exact_vm_capability` fail-closed，禁止用 V2 虚拟储备冒充 VM。
7. **本地索引**：新增 `@zerotrace/local-index` 覆盖区间与 Transfer 去重。未覆盖区间不得当成空持有人。
8. **Token 捕获**：`@zerotrace/token-market-capture` 经注入 Transport 做双 Operator 起源/日志；Worker 在有 runtime.tokenCapture 时真正执行 Stage DAG。业务代码不直接 fetch Provider。
9. **Flap 起源**：P0 创建交易的 `receipt.contractAddress` 不是 Token 本身。起源 COMPLETE 需要 traces；回执不一致才是 FAIL。
10. **生产鉴权**：`NODE_ENV=production` 且无 OIDC 时 HTTP 除探活外 503，不得开放匿名写。
11. **Provider 平面**：业务包不得直连 RPC URL。选择按 chain/method/height/archive/trace/finality/独立性/预算/成本/延迟/错误率/响应上限/取证等级，不按厂商名。BNB 官方公共端点禁止 `eth_getLogs`。缺 Key 启动不失败，依赖 Case 保持 PARTIAL/BLOCKED。付费 Key 先 SHADOW，达标才 PRIMARY。
12. **Trace 闭合**：NodeReal MegaNode 与 Ankr 免费 Key 已探测到 archive/`eth_getLogs`，但 `debug_traceTransaction`/`trace_transaction` 被套餐拒绝。dRPC 公共与 1rpc 同样无 TRACE。P0 工厂/内部 CREATE 改为：双 Operator 锁定 tx/receipt/code 后，用 SQD `binance-mainnet` CREATE traces 在创建区块匹配 Token；不得用回执地址或 Explorer 替代。RPC TRACE 插槽保持 UNCONFIGURED，直到有可探测的 debug/trace 端点。
13. **低成本存储平面**：默认 `ZEROTRACE_STORAGE_PROFILE=LOW_COST_CASE`。PostgreSQL 只做控制面（缺省则本地 JSON）；大规模事实写 Hive 分区 Parquet；DuckDB/hyparquet 查询 Parquet；`LocalFsArtifactStore` 保存内容寻址证据。ClickHouse、MinIO、本机 Archive 可选，缺省不影响启动。Unknown 不得变成 0。未来 1–2TB 切 `SELECTIVE_MARKET_INDEX` 时保留同一 Parquet 与案件 Evidence，Archive 仍走能力平面远程接入，不建设完整 BSC Archive。
