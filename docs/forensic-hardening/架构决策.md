# 架构决策（硬化阶段）

1. 取证模式 PostgreSQL 写失败必须 fail-closed；研究模式才允许进程内信封。
2. 变化点是 `MODEL_HYPOTHESIS`，不是确定性活动边界。
3. V3 Exact 在缺少 Tick/Range/LiquidityNet 时 `UNKNOWN_CONSTRAINT`，禁止虚拟储备冒充可兑现 U。
4. 正式入口只接收链 + Token + 快照策略；单元格 JSON 仅调试页。
5. Replay 必须重算并比对 resultHash。
6. Lot 排序用数值区块/槽位，HIFO 用单位成本；`ACTUAL_SOURCE` 禁止回退 FIFO。
7. 同账户分录计入 unmatched，禁止把借贷同一金额当成自动平衡。
8. Quote 只有 `quoteSettlesInU === true` 才计入可兑现 U。
