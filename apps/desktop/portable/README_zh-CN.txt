ZeroTrace 链上取证工作站·便携版
==================================

这是 Windows 10/11 x64 免安装版。请先解压完整 ZIP，再双击 ZeroTrace.exe；不要直接在 ZIP 预览窗口中运行。

目录要求
----------

- ZeroTrace.exe、zerotrace-api.exe、zerotrace-portable.json 和 config 目录必须保持在原相对位置。
- 首次启动会在程序旁创建 ZeroTrace-Data。该目录是便携数据目录，移动软件时应与程序一起移动。
- 请确保当前目录可写，不要放在 Program Files 等受限目录。
- 系统需要 Microsoft Edge WebView2 Runtime；Windows 10/11 通常已包含。

数据与权限
----------

- ZeroTrace 始终只读：不保管私钥，不签名，不广播交易，不自动划转资金。
- 条件交易与资金结果只是模拟，不会触发真实交易。
- 免费数据采购预算默认为 0。凭据不等于允许付费。
- 如需接入已授权的免费/只读数据源，可将 .env.example 复制为同目录 .env 后填写。发布包不包含真实凭据。
- xapid 的具体服务身份尚未验证，请勿猜测网址、认证头或价格，也不要向未验证端点发送请求。

取证边界
----------

便携数据目录不会伪装成 PostgreSQL、ClickHouse 或对象存储。正式取证模式在缺少持久存储、原始产物、来源校验或重放能力时会失败关闭；未知、不可用、过期和数据源下线不会被当作数字 0。

完整性校验
----------

SHA256SUMS.txt 列出发布包内文件的 SHA-256。本开发交付仍可能没有 Windows 代码签名；在正式分发前需独立完成签名与清洁机验收。
