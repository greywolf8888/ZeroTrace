# Arc 活动任务支线

本分支是 ZeroTrace 的 Arc 活动任务与验证材料，**不是 ZeroTrace 主项目，也不是 ZeroTrace 生产完成的证明**。本分支保留活动代码、原件、旧报告、部署导出与历史品牌记录。

ZeroTrace 唯一主线：[main](https://github.com/greywolf8888/ZeroTrace/tree/main)。

活动沿革：Arc Task Ledger → Arc USDC 核验器 → 历史 BundleMark 导出。过去的运行收据保留原日期、源码与范围；本次分类不改写历史链上事实，也不修改独立仓库。

## 分支用途

- 本分支承接 Arc 活动工作。
- codex/bundlemark-brand-20261008 与 deploy/arc-task-ledger-northflank 为历史活动来源，停止作为独立开发主线。
- 主项目开发、协作交接和默认入口均使用 main。
- 活动脚本、数据库迁移、云端作业不能当作 ZeroTrace 主系统启动步骤。
